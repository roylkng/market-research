# DR001 H021 prospective research gate

This directory stores immutable materializations of the frozen
`DR001-H021-TIER-A-GATE-v1` research-routing rule.

Inputs:

- the sealed DR001 Tier A dossier pack;
- a valid H021 28-35 day primary EPS-revision comparison.

Outputs never authorize a portfolio position. Only a strictly positive H021 revision
that also belongs to the frozen H021 primary top decile may advance a Tier A company
to the next research stage: valuation plus red-team review.

The frozen rule is documented in:

`research/DR001_H021_TIER_A_GATE_V1.md`
