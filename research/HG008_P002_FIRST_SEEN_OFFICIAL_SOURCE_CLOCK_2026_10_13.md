# HG008-P002: Hourly NSE First-Seen Event Discovery Clock

**Preregistered 13 October 2026. First eligible source-clock observation:
14 October 2026, 00:00 UTC or later.** Pilot lasts until 14 November
2026, 00:00 UTC. This is original NSE **source intake**, not a forecast.

## Missing operational link

HG008-P001 froze five historical 90/180-day transaction-stage
cumulative-incidence forecasts, with a strict eight-hour window from
the original exchange publication of a genuinely new event stage.
It explicitly refuses forecasts for existing months-old survivors.

The existing SS002-P001 daily surveillance captures the previous
completed India trading date, often hours after exchange news,
sometimes the next evening. That cannot reliably establish an
independently approved new-stage source/forecast within eight hours.
Treating backfilled daily records as first-seen predictions would
be look-ahead research fraud.

## New bounded original-source observer

- Source: existing native NSEClient corporate announcements, official
  HTTPS NSE API only, no third-party search, evasion or rate-limit bypass.
- Query window: current and previous India-local dates, with *actual*
  UTC acquisition timestamp stored. Previous date is needed for
  midnight/delayed source publication, but cannot turn an earlier
  notice into a valid new-stage observation.
- Cadence: at most one original source request per UTC hour during
  the 14 October–14 November 2026 proof-of-source pilot. GitHub
  Actions cron runs are *best effort*, never guaranteed timely.
- Raw bytes: exact original UTF-8 JSON, SHA-256, content-addressed,
  compressed for Git retention. Every run includes either an
  immutable source snapshot or a network/source-schema failure receipt.
- Canonical NSE announcement ID: original symbol, exact original
  sequence, authoritative exchange-reported dissemination timestamp
  and SHA-pinned attachment URL when an approved NSE archive link exists.
- Classifier: existing SS002 taxonomy of keyword hints only, not an
  independent transaction-stage economic interpretation.

Every candidate records whether the difference between source
broadcast time and actual acquisition is 8 hours or less, greater
than 8 hours, before the future protocol start, or implausibly
future-dated relative to the local collector timestamp.

**None of these clock categories establishes HG008 forecast
eligibility.** For all candidates:
- official original attachment PDF is not fetched or semantically approved;
- exact listed ISIN is not certified from this source;
- previous same-security transaction stages and survivor status are
  not independently checked;
- original stage/track/milestone is not verified;
- first-ever eligible stage publication is not independently established;
- valid frozen HG008 stage forecast count remains ZERO.

A human/agent reviewer must later acquire, SHA-pin and independently
review the actual original PDF pages, resolve issuer/ISIN, compare
prior episode chronology, and commit a probability forecast no later
than eight hours after **verified** first-stage public timestamp.
A delayed source clock is an abstention, not something to backdate.

## Operational integrity

- Module: src/marketlab/hg008_intraday_discovery.py
- CLI: scripts/capture_hg008_intraday.py
- Tests: tests/test_hg008_intraday_discovery.py
- Workflow: .github/workflows/hg008-intraday-discovery.yml
- Source root: research/prospective/hg008-p002/

The workflow can never trigger itself on the newly saved source files;
only the workflow or collector code changes can trigger a merge run.
An hourly cron is independently configured. Before 14 October, the
reviewed merge-driven run must skip acquisition.

The query is bounded to 8MB of original UTF-8 JSON and 3,500
source rows per poll. Duplicate exact announcements collapse
canonically, conflicting sequence/symbol records fail closed.
HTTP/source failure creates an honest missing-data receipt with
no invented zero events or false first-seen forecasts.

Raw source/packet digest, original NSE query and UTC time are
retained. The official NSE endpoint can be unavailable or delayed;
this is never silently substituted by another source.

## Scientific boundaries

HG008-P002 is not an HG008 calibration result, not a new alpha
discovery trial, not stock return evidence and not permission to
apply HG006 unconditional base rates to months-old cases.

Outcomes cannot be scored before a genuine 90/180-day maturity.
Historical survivors, correlated transaction tracks, right
censoring, case-specific financing, diluted share counts, liquidity
and multiple-testing corrections retain independent gates.

**No portfolio eligibility, trade, position, company expected return
or live capital may be generated by the source clock.**
