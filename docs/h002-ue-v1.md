# H002-UE-v1: frozen prospective unexpected-earnings signal

## Purpose

H002 asks whether positive unexpected earnings are followed by post-earnings-announcement drift in the frozen U001 Indian non-financial research universe.

This document freezes the first prospective signal implementation. It does **not** authorize paper execution or live capital.

## Why this model

The feasibility pilot already used the literature-style Indian PEAD variable:

`UE = (EPS_t - EPS_t-4) / Price_day_minus_2`

NSE/IGIDR research on Indian equities defines UE this way and reports higher post-announcement abnormal returns for higher-UE portfolios. Other India-focused PEAD work also uses same-quarter prior-year earnings as the expectation proxy. The existing H002 pilot was designed around that signal.

Changing H002 now to analyst consensus, an optimized time-series model, momentum, valuation or an LLM-derived score would move the hypothesis after seeing historical results. Those alternatives require separate hypothesis/version ids.

## Frozen expectation model

Expected EPS is:

`expected_eps_t = basic_eps_t_minus_4`

Requirements:

- same issuer,
- same reporting quarter,
- same accounting basis,
- prior source was public before the current filing,
- EPS is comparable across corporate actions under a versioned pre-event adjustment policy.

If any requirement is not met, the event receives `NO_SIGNAL` rather than an imputed expectation.

## Frozen primary signal

`unexpected_eps = actual_basic_eps - prior_year_basic_eps`

`UE = unexpected_eps / price_day_minus_2`

`price_day_minus_2` means the official close of the second prior NSE trading session relative to the local calendar date of the exchange publication. Issue #6 will implement the trading-calendar and price-source mechanics. Until then, H002-B accepts the price as a provenance-bearing input but does not create a paper position.

### Buckets

- `POSITIVE`: UE > 0
- `ZERO`: UE == 0
- `NEGATIVE`: UE < 0
- `NO_SIGNAL`: missing, non-comparable or invalid required input

No winsorization and no cohort-relative quantile thresholds are used in v1.

## EPS field

Use `basic_eps` from the consolidated statutory result where U001/H002 eligibility requires consolidated reporting. The event parser already prefers the combined continuing-and-discontinued basic EPS field and falls back to continuing operations only when the combined field is absent.

Do not substitute adjusted brokerage EPS, management-adjusted EPS or later restated EPS without a separately versioned transformation.

## Corporate actions

Per-share comparability is mandatory.

If a split, bonus, rights issue, merger or other share-basis event makes the prior EPS non-comparable, H002 returns `NO_SIGNAL` unless a deterministic adjustment factor based only on information public before the current result is available and versioned.

The system never treats "probably comparable" as evidence.

## Timing / leakage rules

The following are forbidden:

- prior EPS published after the current filing,
- current-quarter analyst commentary published after the filing,
- later earnings-call transcripts used as pre-result expectation inputs,
- future corporate-action information,
- post-result prices used in the denominator,
- choosing a different expectation model after observing the return.

## What is deliberately deferred

### Analyst-consensus surprise

Timestamped consensus EPS could be economically superior to the seasonal-naive expectation, but reliable historical/prospective consensus coverage, licensing and timestamp fidelity have not been established for the 100-company panel. It must not silently replace the H002 rule.

### Standardized SUE

Scaling seasonal EPS surprise by a rolling historical standard deviation is also supported by the broader PEAD literature. It changes the signal definition and will be evaluated only as a separately registered model/hypothesis after H002-UE-v1 begins prospective collection.

### Paper positions

Entry, exit, holidays, circuits, benchmark prices and execution costs belong to H002-C (#6). H002-B only freezes the signal and its input provenance contract.

## Promotion discipline

The sign result from the historical 24-name feasibility pilot remains inconclusive. Prospective evidence must be collected under this frozen rule before any claim of predictive value.
